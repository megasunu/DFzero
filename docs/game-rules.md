# 게임 규칙 사실 (MEMORY.md에서 옮김)

처음에는 MEMORY.md에서 길어진 규칙 설명을 옮긴 파일이다(2026-10-06). 2026-10-16부터 할 일은 작업 보드(이슈)에 있고
이 파일은 게임 규칙만 둔다. 코드가 바뀌면 이 파일을 코드와 같은 커밋에서 고친다. 값이 맞는지는 코드/테스트가 정답이다.

## 상점 판매가

판매가 = 가격의 20%를 1골드 단위로 **올림**(`shop_system.판매가`, 2026-10-08부터 - 그 전엔 버림이라 5골드 미만은 0골드). 가격 1~5 -> 1골드, 가격 0/없음 -> 0골드.

## 주류 / 취기 / 만취 (2026-10-08)

- 주류(item_food.py "주류", 소모품 "주류" 탭, 소지품 "소모품")를 마시면 대상별 회복을 따로 굴린다 - HP `..+건강보정치`, MP `..+주문시전보정치`. 맥주/와인/럼주 2d4, 슈시아 특제/엘븐 드레이크 샴페인 `(2차수)d4`(마시는 캐릭터의 전직 차수 1~4 -> 2/4/6/8개). 다크 데킬라/신성한 포도주 회복 미정. 가득 차 있어도 마실 수 있다(포션과 다름).
- 회복을 먼저 굴린 뒤 상태이상 "취기" +1중첩(최대 3). 중첩당 명중보너스 -1, 매력 -1(전투 밖 `캐릭터_유효능력치`에도 반영). 3중첩에서 또 마시면 취기가 사라지고 "만취". 만취 중에 마시면 회복만.
- 만취: 자기 차례에 조종 불가(`아군_차례인가` False, `턴_넘기기`가 `ctl_battle._만취_턴`으로 대신 행동). 1/4로 수면 2~5턴(이번 턴 포함, 잠든 동안 판정 없음, 수면 규칙 그대로), 아니면 일반공격+쓸 수 있는 스킬 중 하나를 적/아군 무작위 대상에게(자신 대상 스킬은 자신에게, 실패하면 일반공격).
- 취기/만취는 "전투후유지" - 캐릭터["상태이상"]에 남아 전투 시작 때 참가자로 옮기고 끝나면 되돌려 쓴다(세이브 형식 그대로, 키는 원래 있던 "상태이상"). 마을 휴식("휴식시해제")으로만 풀린다.
- 전투 중 마시기는 보조행동 1개, 자기 자신만. 전투 밖은 파티원 아무나.

## 레벨 6 특성, 속성, 레벨 8

**레벨 6 특성**: 웨펀마스터 '웨펀마스터'(명중+1/뎀+1) -> '무기의 극의'(무기별: 소검 무기계수 d10 / 도 뎀+2 / 둔기 명중 시 20% 기절(건강, 10+근력보정치, 1턴) / 대검 명중-1·뎀+4 / 광검 일반공격·일반공격취급 +1d6(치명타에 안 늘어남)). 특성 효과 원소에 "무기조건" 지원. 옛 세이브는 불러올 때 이름만 바꿈. 레인저 레벨 6 = '리볼버 강화'(리볼버 들 때 치명타범위+1). 엘마 레벨 6 메모라이즈 = 하급마법을 보조행동으로(쇼타임->일반행동->보조행동 순, 특성 "보조행동대체타입", 주문 명중+1은 삭제). 같은 버프스킬 재사용은 중첩 없이 지속턴만 갱신(인스턴스 "출처스킬"). 스킬의 일반행동을 낼 수단이 둘 이상이면 전투 화면이 행동 선택 팝업(gameflow.스킬_행동선택지, 아군_스킬사용 행동지불). 다른 전직 레벨 6은 사용자가 이어서 수정 예정.

**속성**: 이름은 무속성/화속성/수속성/명속성/암속성(미정->무속성, 무기는 전부 무속성). 무기 주사위 쓰는 피해는 무기 "속성", 아니면 스킬 속성(스킬 "속성추가피해" 부분은 자기 속성). 저항 0.5/취약 2/면역 0, 속성강화·속성내성은 합연산 1+0.1x(강화-내성)(0 밑으로 안 감)을 방어 뒤 최종피해에 곱함, 저항/취약/면역과는 곱연산. 화/수/명/암에만, 무속성은 강화·내성 없음("전체"도 제외) - 사용자 결정 2026-10-12. 캐릭터 "내성"/"면역(상태이상)" 칸과 공중사격은 여전히 전투에서 안 읽힘. **레벨 8 "스킬획득"**(MP10·행동 없음·10턴, 습득방법 "레벨습득"이라 [스킬습득]에 없음): 웨펀 오버드라이브(명중-1/뎀+3), 스트라이커 강권(근력+2/치명타주사위+1), 레인저 데스 바이 리볼버(치명타피해증가+치명타확률증가 버프, 리볼버 들 때만 - 스킬 "버프무기조건"), 엘마 엘레멘탈 번(속성강화+1, 화/수/명/암 공격만 - 무기는 전부 무속성이라 일반공격엔 안 붙음), 크루세이더 용맹의 축복(아군 근력·지능 +시전자 주문보정치). 데스 바이 리볼버/엘레멘탈 번 **레벨 6 특성은 삭제**(옛 세이브는 불러올 때 특성 뺌). 버프 중첩량 수식은 시전자 기준 1회, 0 이하면 안 건다. 치명타주사위: 캐릭터/몬스터 키(기본 1, 치명타 때 더 굴리는 피해 주사위 수) + 버프 치명타피해증가/디버프 치명타피해감소·특성으로 증감, 최소 0. 무기 주사위가 있는 식은 무기 주사위만 늘고, 0개 항은 0. 펌블범위 = 1 + 공격자 펌블확률증가/감소 + 대상 피격펌블증가/감소(최소 0) + 얀데레 특성이면 (20 - 유효 치명타범위)(그때그때 계산 - 10-19 사용자 결정).

## 블러드 러스트·버서커·소울브링어 골드 스킬 (2026-10-20 사용자 결정, #247)

## 체력/마나/포션

**지금 규칙(전부 `main-branch`에 병합됨):** 최대HP = 기본체력 + 올림(레벨 x 기본체력 / 2), 기본체력 = 직업 레벨당체력증가 + 건강보정치(올림은 총합에 한 번, 최소 1). 귀검사 5/격투가 6/거너 4/마법사 4/프리스트 5. 기존 세이브는 불러올 때 재계산(main 병합). 캐릭터에 "레벨당체력증가" 저장(장비 건강 반영용).

몬스터 최대HP도 같은 공식, 기본체력 탱커 6/딜러 5/메이지 4 + 건강보정치(수식 "올림(...)" 지원). 몬스터 AC는 역할군 모두 9+차수+민첩보정치(1차수 기본 10, 2026-10-14 사용자 지정 - 전에는 탱커 7+2×차수/딜러 7+차수/메이지 6+차수). 역할군 차이는 AC가 아닌 다른 쪽에서 둔다. 주문시전능력치 미지정이면 지능(character_data_system.주문시전능력치) - 귀검사/격투가/거너도 MP와 주문보정치가 지능을 따른다.

최대MP = 25 + (레벨-1)x(3+주문시전보정치). 포션 HP (차수)d10+건강, MP (차수)d6+주문, 최소 1 - 정리: [`.memory/sessions/2026-10-02-hp-mp-potion.md`](https://github.com/megasunu/DFzero/blob/3d981e7ac4ecb2776d7ea12be085e260198fa745/.memory/sessions/2026-10-02-hp-mp-potion.md).

회복포션 사용(potion_system.py): 전투 [아이템] = 보조행동 1, 자신만 / 파티원 화면 [포션 사용] = 아무 파티원. 레벨제한·쓰러짐·가득 참이면 불가. 자동전투는 포션 안 씀.
버프포션(item_potion.py, 묶음 없이 낱개): 전투 [아이템]에서만 = 보조행동 1, 자신만. 버프는 "버프이름"을 "중첩"(없으면 1)만큼, 지속턴 "지속턴". 같은 포션 재사용은 지속턴만 갱신. 행동버프는 마신 턴에 바로 는다. 샤프아이(치명타확률증가, 100골드), 가속 포션(일반행동증가), 오거파워 플라스크(근력증가 5중첩), 마나의 속삭임 플라스크(지능증가 5중첩) - 셋 다 10턴, 1000골드. 마을 판매목록에는 없다.
소환 아이템(item_consumable.py "소환 아이템"): 전투 [아이템]에서만 = 보조행동 1, 자신만. 고블린 더스트(10골드, 판매목록 없음, 상점 소모품 "소환 아이템" 탭) = 버프 "고블린소환"(전투종료까지, 중첩). 소환수 고블린(summon_00.py)은 몬스터 고블린과 같은 패턴(1~5 몽둥이질, 6 두번때리기), 1d4+매력보정치·매력판정(사용자 능력치). 쓸 때마다 중첩 +1 -> 사용자 턴 끝에 중첩 수만큼 따로 행동("중첩당공격"). 효도르/정령은 중첩 없음 = 한 번.

## 추가행동 (2026-10-16 사용자 결정 - DnD 5판 추가 공격)
- 캐릭터 `추가공격`(밀리·하이브리드 6/11/16/21레벨마다 +1, 캐스터는 0)만큼 한 턴에 추가행동을 쓸 수 있다.
- **진짜 일반행동**으로 일반공격이나 일반공격취급 스킬을 쓰면 그 턴에 열린다(한 번). 쇼타임행동·보조행동(메모라이즈)으로
  낸 것, 다른 스킬(버프 등)에 쓴 일반행동은 열지 않는다. 열린 뒤에는 같은 턴 안에서 언제든(사이에 보조행동·아이템을 써도)
  일반공격/일반공격취급 스킬을 일반행동 대신 낸다. MP는 그대로 든다. 남은 것은 턴이 끝나면 사라진다.
- 일반공격은 열린 추가행동을 먼저 쓴다. 일반공격취급 스킬도 추가행동이 남아 있으면 그것으로만 낸다(일반행동은 남겨 둔다).
- 자동전투(일반공격/전력전투 모두)도 추가행동까지 일반공격한다. 삼연참 "3+추가공격"은 남은 수가 아니라 캐릭터 수치.
- 상태: `참가자["추가공격_사용가능"]`(턴 시작에 채움, 열면 0) -> `참가자["기타행동"]["추가행동"]`(추가공격 0이면 칸 없음).
- **원펀맨**(공용 퍽 1차수, 10-19 사용자 결정): 일반행동으로 내는 순수 일반공격(열린 추가행동이 없을 때) 한 번에
  남은 일반행동을 모두 합친다 - 배수 M = 일반행동 수 x (1 + 캐릭터 `추가공격`), 그 턴은 일반공격을 더 못 한다.
  명중 굴림 한 번(치명타·펌블도 한 번에), 명중 보정 전체(능력 보정·숙련·명중보너스) x M, 보정공격력 M번 굴림(치명타면
  굴림마다 주사위가 는다), 데미지보너스 x M, 빗나가면 집요함 x M(얀데레 펌블이면 더 곱함). 추가피해(장전·일반공격
  추가피해·마봉)와 명중 시 상태이상은 한 번(`resources.원펀맨_합치기`, `attacks.일반공격_실행(배수=)`).

## 자동전투

- 일반공격 방식: 일반행동이 남는 동안 지정 가능한 적 중 무작위 하나를 일반공격. 1차 직업이 마법사(마법사/엘리멘탈마스터)면 매직미사일(MP 0)을, 쓸 수 없으면 일반공격(2026-10-12, `ctl_battle._자동전투_대체스킬`).

- 전력전투 방식(`ctl_autobattle.전력전투_한_차례`): 해제 -> 회복(HP 절반 이하, 비율 낮은 아군) -> 버프(지속 지나야 다시) -> 자원/소환 -> 공격(기대 피해 = 수식 평균 x 횟수 x 맞는 적 수가
  가장 큰 스킬, 일반행동 스킬은 일반공격 기대 피해 이상일 때만, MP 아끼지 않음). 대상은 가장 약한 적. 남은 일반행동은 일반공격/매직미사일.
- 전투로그 자세하게: 판정 줄 앞에 "주사위(15)+능력 보정(2)+출처(값)"와 "AC 계산: ...", 명중하면 "피해 계산: 식(굴린 값)+출처(값) = 합 → 최종",
  내성은 "DC 계산: 식 = 값"/"내성 계산: 주사위(눈)+스탯 보정(값) = 합". 출처는 버프/디버프/상태이상/특성/칭호 하나씩(남는 값은 "기타").

## 스킬 밸런스 기준 (2026-10-21 사용자 지침)

부가효과 없이 적 1체를 즉발로 공격하는 단일 대상 스킬이 기준이다. **무기는 1d8 무기를 낀 것으로 보고 분석한다.**
**기대값은 보정치 +3으로 본다: 1d8+보정치 = 7.5, 1d8 = 4.5**(2026-10-22 사용자 지침). 직업별 비교 기록은 `docs/balance/`.
직업 하나씩 스킬을 이 기준과 견줘 본 뒤 전체 밸런스(샌드백 전투, 4인 파티 측정)를 본다.

**기본 행동**

| 행동 | 기준 피해 |
|---|---|
| 일반행동 일반공격 | 1d8 + 보정치 |
| 추가공격(일반행동 사용 시 발동) | 일반공격과 같다 (1d8 + 보정치) |
| 반응행동 | 일반행동과 같다 (1d8 + 보정치) |

**얹는 값** - 위 공격에 얹어서 쓰고, 한 턴에 여러 개를 함께 쌓을 수 있다.

| 비용 | 더하는 피해 |
|---|---|
| 보조행동 | 1d8 (보정치 없음) |
| 5MP | 1d8 또는 보정치 중 하나 (스킬을 설계할 때 정한다 - 쓸 때 고르는 것이 아니다) |
| 10MP | 1d8 + 보정치 |
| 20MP | 2 × (1d8 + 보정치) |
| 30MP | 3 × (1d8 + 보정치) |

**범위공격** (주대상 1체 + 좌우 각 1체, 최대 3체. 구석이면 2체)
- 3체 합산 피해 = 기준값의 1.5배가 목표.
- 3체 사이 분배 비율과, 구석에서 총합을 유지하는지는 스킬마다 다르게 설계할 수 있다.
- MP를 쓰는 스킬이고, 이 배율은 MP 소모량과 상관없는 고정 목표다(MP 소모량은 사거리·부가효과 등으로 스킬마다 정한다).

**전체공격** (전장의 모든 적)
- 마리당 피해 = 기준값의 1/3배가 목표, 적 수 제한 없음.
- MP를 쓰는 스킬이고, 이 배율도 MP 소모량과 상관없는 고정 목표다.

**지속피해**
- 턴당 피해 = 기준값 × 0.5배 (2턴 지속 = 합계 1배, 3턴 = 1.5배, 4턴 = 2배).
- 기준값은 그 효과가 걸리는 대상의 기준(단일/범위/전체 각각의 기준값)을 그대로 쓴다.
- 즉시 피해와 지속 피해는 한 스킬에 같이 있을 수 있지만 서로 영향을 주지 않고 각자 자기 기준대로 따로 계산한다.

**추가공격과 차수계수**
- 차수가 오를수록 추가공격이 생긴다.
- 추가공격을 쓰지 못하는 일반행동 스킬은 대신 차수계수로 밸런스를 맞춘다.
- **차수는 일반공격 몫에만 곱한다**(2026-10-22 사용자 지침 - 전에는 MP 몫까지 곱했다). 일반공격은 차수가 오르면 추가공격으로
  기준값의 공격을 여러 번(4차수면 4번) 하므로, 추가공격을 쓰지 못하는 일반행동 스킬의 기준은 (일반공격 x 차수) + 얹는 값이다.
  예) 단일 일반행동 + 20MP 스킬의 기준은 7.5 x 차수 + 15 - 2차수 30, 3차수 37.5, 4차수 45.
- 스킬이 다른 스킬의 일반행동을 사실상 써야 하면(환영폭쇄는 분신을 먼저 깐다) 그 일반행동도 비용에 넣는다. 횟수가 차수를 이미
  담으면(분신 수 = 차수+2) 피해 식에는 차수를 넣지 않는다.
