# 스킬 전수 점검 (2026-11-06, 작업 14)

데이터의 "설명"과 `docs/game-rules.md`가 말하는 효과가 **실제 전투에서** 일어나는지 스킬마다 한 번씩 실행해 대조했다.
값은 데이터 파일이 아니라 실행 결과로 확인했다(CLAUDE.md).

## 방법

- **스킬 225개**(공용 6 + 직업·전직 219, 반응 14·던전 2 포함). 직접 쓰는 209개는 레벨 10 파티(그 스킬의 전직 + 다른 직업 3) 대
  타우 아미·고블린 셋 전투에서 쓴다. 사용 조건(자원·무기·소환수·체이서·텐션행동)은 사용 불가 사유를 보고 갖춘 뒤 쓰고(표의 "조건"),
  연계스킬은 앞 스킬을 써서 이어 나가게 했다. 쓴 뒤 3라운드를 더 돌려 지속턴·지속공격·소환수·캐스팅을 거쳤다.
- 대조한 것: 사용 가능 여부, 예외, MP·HP 비용, 행동 소모, 타격 수·대상 수, 붙은 버프·디버프·상태이상과 지속턴, 내성 결과,
  휴식당 횟수 감소, 전투 기록 문장(dict·None·TODO가 그대로 보이는지), **레벨 12 스킬강화**(같은 시드로 다시 써서 타격마다 피해 x1.5, MP x2).
- 설명문의 숫자(턴·MP·휴식당/전투당·공격 횟수)를 데이터와 맞춰 보고, 엔진이 읽지 않는 데이터 키를 찾았다(스킬·특성·몬스터·장비·상태이상).
- **반응스킬 14개**는 `test_combat_effects`의 반응 전투, **던전스킬 2개**는 `test_dungeon_skills`가 실제로 발동시킨다 - 골든에 예외 없음.
- **몬스터 패턴**은 `test_combat_monsters`가 78종의 패턴을 하나씩 강제로 실행한다 - 골든에 예외 없음. 골든의 로그 전체를 문장으로 바꿔 본 결과는 아래.
- 영구 검사: `tests/test_skill_audit.py`(직접 쓰는 스킬 전부 - 조건을 갖추면 쓰이고 기록 문장이 깨지지 않고 MP·버프·지속턴이 데이터대로,
  스킬강화 x1.5/x2, 스킬 데이터 키는 엔진이 읽는다).

(반응스킬 조건식 설명), 패턴·자원 이름(키가 곧 이름). 특성의 `오토가드.대상종류/행동소모`, 상태이상의 `중첩감소`(지속턴 감소는 `flow._지속피해형_지속턴`),
