# 밸런스 체크 - 승률용 전투

`python tools/balance_sim.py 전체 --승률` 결과(#691). 파티원 네 명의 행동 패턴을 돌아가며 다듬어(전력전투에서 시작, 같은 학습 판으로 후보를 맞대어 이기는 것만 받아들임) 그 파티의 최고 승률을 찾았다. 승률은 모두 학습에 쓰지 않은 검증 판에서 다시 잰 값이다. 분석 승률은 같은 검증 판의 분석용 전투(#690, 무작위 행동)다.

- 파티 12개, 학습 40판 + 검증 40판, 반복 2, 변형 후보 5개, 스킬 후보 4개
- 평균 승률: 분석 69.0%, 전력전투 87.1%, 최고 패턴 86.7%
- 규칙지문 `7278b0461542e511`, 커밋 `2ca3b18`

## 전직

기여는 선형 회귀(파티 승률 ~ 파티에 든 전직)로 구한 "평균 전직 대신 들어가면 달라지는 승률"이다. 최고 기여가 분석 기여보다 크면 **잘하면 강한** 전직(손을 많이 탄다), 둘 다 크면 **누가 해도 강한** 전직이다.
