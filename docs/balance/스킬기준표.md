# 스킬 밸런스 기준표

`tools/balance/skill_balance.py`가 만든 파일이다 - 손으로 고치지 않는다. 스킬 데이터나 기준을 바꾸면
`python tools/balance/skill_balance.py`로 다시 쓴다(`tests/devtools/test_skill_balance.py`가 최신인지 검사한다).

- 기준 빌드: 무기 1d8, 보정치 +3, 주문시전보정치 +3, 추가공격 차수 - 1, 명중보너스 +0, 데미지보너스 0.
- 칸은 `기대 / 기준 (비율)` - 비율은 기대가 기준보다 몇 % 많은지. 기준은 `docs/game-rules.md` "스킬 밸런스 기준".
- 대상: 단일은 타격 합, 범위는 3체 합(기준 1.5배), 전체는 적 하나당(기준 1/3배), 2체는 2체 합(기준 1배).
- 공격단계가 나뉜 스킬(대상 칸에 `+`)은 단계마다 적 1체 즉발 1타로 바꿔(범위 ÷1.5, 전체 x3) 더한 기대를 비용 한 번의 기준과 견줬다. 앞 단계가 맞아야 나가는 단계는 앞 단계가 하나라도 맞을 확률을 곱했다(전체는 3체).
- 명중은 70%(d20 + 3 >= AC 10)에 견준 배율을 곱했다. MP 5는 1d8(4.5)로 봤다.
- 비고의 "부가효과 포함"은 피해로 바꿔 넣은 효과다 - 무력화CC 1턴 = 약화CC 2턴 = 기준값 1배, 지속피해형은 턴당 피해 ÷ 0.75, 시전자 AC 버프는 AC 1당 턴마다 0.05 x 차수 x 7.5(명중·내성 실패 확률을 곱함, 대상 내성 능력치 14). 몹몰이는 재지 않는다.
- 비고의 "반영 안 함"은 계산에 넣지 않은 키다(홀딩 등) - 그 스킬은 그 키 없이 본 값이다. "키: 까닭"은 피해가 같거나 기준빌드에서 0인 키다.
- 습득 차수와 상관없이 1~5차수를 모두 셌다. 전투를 돌린 값이 아니다(수식 기대값).
- 소환수(메카)는 행동표 평균(라운드당)의 3라운드 합을 기준과 견준다(지속턴이 더 짧으면 그만큼, 자폭은 소환수 딜표에 따로).
