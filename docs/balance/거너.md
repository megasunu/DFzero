# 거너 전직 밸런스 측정 (2026-11-06~07)

`tools/balance_sim.py`로 잰 값이다. 기록(승률패턴·슬롯별 누적·비교)은 `patterns.json`, 규칙 지문 `4e67458d0ce0feea`
(`main-branch` `908285b` + 도구 수정 `afc3de6`). 규칙(game/data·game/system)이 바뀌면 이 표는 옛 규칙의 값이다.
조건·시드·판 수·읽는 법·한계는 [요약](요약.md)에 한 번만 적었다. 전직 간 비교도 거기에 있다.

- 전직마다 1200판(처음부터 단계 1~4 각 200판 + 이어서 400판) 학습, 그 뒤 **같은 판 비교 400판**(시드 500000~500399 고정,
  기본 파티 200 + 다른 파티 5개 각 40). 같은 판 비교의 차이는 ±10승 안쪽이면 잡음으로 본다.
- 다시 재려면 `python tools/balance_sim.py <전직> --처음부터 --판 200`, `--판 400`, `--비교 --판 400` 순서.

## 정리

1. 거너 다섯은 일반공격만 172~190으로 좁게 모여 있고(43~48%), 승률패턴은 205~244다.
2. **패러메딕 장갑강화 +74**가 거너에서 가장 큰 단일 효과다(완충모듈 +34도 큼). 정화모듈은 -10.
3. **런처 양자폭탄 +48, 메카닉 메카드롭 +48**이 그다음이다. 런처는 슈타이어 대전차포(+29) 말고는 +11 이하다.
4. **레인저는 가장 좋은 스킬이 웨스턴파이어 +21**로 거너 중 가장 밋밋하다. 손해인 스킬도 -4가 가장 낮다.
5. 스핏파이어는 빙결류탄 +31, 섬광류탄 +29.
6. 거너 공용 반응스킬 패스티스트 건(전투 시작)·건가드(피격)와 메카닉 회심의 랜드러너는 저절로 나가 첫 차례 비교가 0이고 횟수를 세지 못한다.
