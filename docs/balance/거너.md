# 거너 전직 밸런스 측정 (2026-11-07, #593 도구 수정 뒤)

`tools/balance_sim.py`로 잰 값이다. 기록(승률패턴·슬롯별 누적·비교)은 `patterns.json`, 규칙 지문 `2c1a5eedd9535c2c`
(`main-branch` `dc25e21` + 도구 수정 `31b5c1f`). 규칙(game/data·game/system)이 바뀌면 이 표는 옛 규칙의 값이다.
조건·시드·판 수·읽는 법·한계는 [요약](요약.md)에 한 번만 적었다. 전직 간 비교도 거기에 있다.

11-06~07 측정(지문 `4e67458d0ce0feea`, #591)의 표를 이 측정으로 바꿨다 - 옛 값은 git 이력에 있다. 이번 도구는 반응·연계 스킬을
행동 후보에서 빼고(슬롯에 넣어도 쓸 수 없다) 실제로 나간 횟수를 전투 로그에서 세며, 최고 단일 스킬로 만든 패턴 둘도 승률패턴 후보로 본다(#593).

- 전직마다 1200판(처음부터 단계 1~4 각 200판 + 이어서 400판) 학습, 그 뒤 **같은 판 비교 400판**(시드 500000~500399 고정,
  기본 파티 200 + 다른 파티 5개 각 40). 같은 판 비교의 차이는 ±10승 안쪽이면 잡음으로 본다.
- 다시 재려면 `python tools/balance_sim.py <전직> --처음부터 --판 200`, `--판 400`, `--비교 --판 400` 순서.
