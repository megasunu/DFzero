# 테스트 지도

어떤 테스트 파일이 무엇을 지키는지의 표다. `.claude/rules/tests.md`에서 옮겼다 - 규칙 파일은 `tests/`를 건드릴 때마다
맥락에 통째로 붙으므로 긴 표는 여기 둔다.

- **통째로 읽지 않는다.** 주제로 찾는다: `grep -n "<주제어>" docs/test-map.md` (예: `grep -n 넨마스터 docs/test-map.md`).
- 새 테스트 파일을 만들거나 파일의 주제가 넓어지면 그 행을 같은 병합 요청에서 고친다.
- 방식: "정확한 값"은 단언, "골든"은 `tests/golden/` 비교, "규칙"은 구조·데이터 검사다.
